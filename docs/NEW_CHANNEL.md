# 새 인스타 채널 추가 체크리스트

갱신: 2026-11-04 · '오늘의 3분 뉴스'를 만들며 실제로 거친 순서를 정리했습니다.
심리테스트 같은 새 채널을 만들 때 Claude에게 "새 채널 만들자"라고 하면 이 순서대로 안내합니다.

## 이미 있어서 다시 안 해도 되는 것

| 항목 | 이유 |
|---|---|
| 업무용 메일 `dailycard.lab@gmail.com` | 새 메일 대신 `dailycard.lab+채널이름@gmail.com` 별칭을 씁니다 (같은 받은편지함으로 옴) |
| 페이스북 계정, 메타 앱 `dailycard-newsbot` | 앱 하나에 인스타 계정을 여러 개 붙일 수 있습니다 |
| 비즈니스 포트폴리오 `dailycard.lab` | 포트폴리오 하나에 계정을 계속 추가합니다 |
| Claude API 키 | 같은 키를 씁니다. 채널별 비용은 봇이 따로 기록합니다 |
| GitHub 저장소 `news-bot` | 같은 엔진에 설정 파일만 추가합니다 |

## 새로 해야 하는 것 (순서대로)

### 1. 주제·이름 정하기 (Claude와 같이)
- 채널 이름, 인스타 아이디, 색상 2가지, 게시 시간
- 콘텐츠 규칙(정치 제외 같은 것)이 뉴스와 다른지

### 2. 인스타 계정 만들기 (폰)
1. 인스타 앱 → 프로필 → 계정 추가 → 새 계정 만들기
2. 이메일: `dailycard.lab+채널이름@gmail.com`
3. 설정 → 계정 유형 및 도구 → **프로페셔널 계정으로 전환**
4. 프로필 사진·소개글·첫 소개 게시물 (Claude가 이미지와 문구를 만들어 줌)

### 3. 메타에 계정 연결 (PC, developers.facebook.com)
1. **포트폴리오에 인스타 넣기**: `business.facebook.com/settings` → 계정 → Instagram 계정 → 추가 → 새 계정으로 로그인
2. 같은 화면에서 내 이름에 **전체 액세스 → 관리** 켜기 (금융 정보는 끈 채로)
3. 앱 `dailycard-newsbot` → 이용 사례 → 맞춤 설정 → API setup with Unified login
4. **2. 액세스 토큰 생성** → 「계정 추가」 → 새 계정 → 「토큰 생성」
5. 토큰 창에서 포트폴리오 `dailycard.lab`, 새 인스타 계정 선택 → 광고 계정은 기존 것 선택(없으면 새로 만들어도 비용 없음)
6. 나온 토큰과 계정 ID를 `.env`에 붙여 넣기. 이름은 채널마다 다르게:
   `IG_ACCESS_TOKEN_채널이름=` / `IG_USER_ID_채널이름=`
   - 토큰은 채팅에 보내지 않습니다.

### 4. 텔레그램 승인 (선택)
- 기존 봇 @today3min_news_bot을 같이 쓸 수 있습니다(미리보기에 채널 이름이 표시됨).
- 따로 받고 싶으면 BotFather에서 봇을 하나 더 만듭니다.

### 5. Claude가 할 일
- `accounts/채널이름.yaml` 설정 파일 만들기
- 콘텐츠 수집 방법 정하기 (심리테스트는 RSS 대신 Claude가 직접 만드는 방식이 될 수 있음)
- GitHub Secrets에 새 토큰 이름 등록 안내, 예약 실행에 채널 추가
- `python -m newsbot check --account 채널이름`으로 값 확인

## 처음에 막혔던 점 (다시 겪지 않도록)

- 새 페이스북 계정은 포트폴리오를 바로 못 만들고 **1시간 기다려야** 했습니다. 이제 포트폴리오가 있으니 해당 없음.
- 토큰 창에 인스타 계정이 안 보이면 → **포트폴리오에 계정이 안 들어간 것**입니다 (3-1 단계).
- 첫 API 게시 30분쯤 뒤 메타가 앱을 **예방 조치로 잠시 막았습니다**(오류 "API access blocked", 2026-11-04). 메타 개발자 화면에 들어가니 "액세스 권한이 복원되었습니다" 안내가 떴고 바로 풀렸습니다. 새 채널도 첫 게시 후 같은 일이 생길 수 있으니, 처음 며칠은 게시를 몰아서 하지 말고 결과를 지켜봅니다.
- 비즈니스 인증 창은 「나중에 인증」으로 넘겨도 내 계정 게시는 됩니다.
- 이 토큰은 `graph.facebook.com` 주소에서만 작동합니다.
