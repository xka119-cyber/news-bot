# 뉴스봇 운영 설명서

갱신: 2026-11-04 · 현재 단계: M1 완료 (다음: M2 Claude 요약 작성)

새 인스타 채널(예: 심리테스트)을 만들 때는 [NEW_CHANNEL.md](NEW_CHANNEL.md) 순서를 따릅니다.

아직 자동 게시는 동작하지 않습니다. 단계가 끝날 때마다 이 설명서에 내용을 추가합니다.

## 정해진 내용

- 저장소: https://github.com/xka119-cyber/news-bot (공개)
- 공개 범위: 코드, 카드 이미지, 승인 전 초안, 상태 파일은 누구나 볼 수 있습니다. 비밀값은 올라가지 않습니다.
- 브랜드: 오늘의 3분 뉴스
- 색상: 흰 배경, 남색 글자, 노란 강조색 (M3에서 시안을 보고 바꿀 수 있음)

## 연결된 계정 (2026-11-04 확인)

| 서비스 | 내용 |
|---|---|
| 업무용 메일 | dailycard.lab (계정별로 `+news` 같은 별칭 사용) |
| 인스타그램 | today3min.news (프로페셔널 계정) |
| 텔레그램 봇 | @today3min_news_bot (작동 확인, 내 대화방 메시지 도착) |
| 메타 | 앱 `dailycard-newsbot`, 비즈니스 포트폴리오 `dailycard.lab` (비즈니스 인증은 나중에) |
| Claude API | 개인 콘솔 조직, 워크스페이스 `newsbot`, 월 한도 3달러 (2달러에 알림) |

- 인스타 게시 권한(`instagram_content_publish`) 확인, 하루 게시 한도 100회.
- 메타 연결 과정에서 광고 계정 `dailycard.lab`이 자동으로 생겼습니다. 결제 수단이 없어 비용은 나가지 않습니다.

## 설계서와 달라진 점

- 메타가 이제 **비즈니스 포트폴리오**가 있어야 인스타 토큰을 줍니다(설계서에는 없던 단계).
- 인스타 토큰은 **시스템 사용자 토큰**(메타 화면 표기: 만료되지 않음)입니다. 설계서의 60일 연장 기능(M6)은 "토큰이 살아 있는지 점검" 위주로 바꿀 예정입니다.
- 이 토큰은 `graph.facebook.com` 주소에서만 작동합니다(설계서는 `graph.instagram.com`). 게시 코드(M5)는 이 주소를 씁니다.

## 뉴스를 모으는 곳 (M1, 균형형)

- 연합뉴스(경제·산업), 동아일보(경제·과학), SBS(경제·생활), 매일경제(부동산), 전자신문, ZDNet Korea
- 기사 본문은 가져오지 않고 **제목·짧은 요약·링크·언론사·시각**만 씁니다.
- 최근 12시간 기사 중 같은 기사·비슷한 제목은 하나만 남기고, 최근 3일 안에 쓴 기사는 뺍니다.
- 정치·선거·사건사고·연예 가십 단어가 들어간 기사, 사진·영상·인사·부고 기사는 1차로 뺍니다. M2에서 Claude가 한 번 더 거릅니다.
- 언론사별로 고르게 섞어 후보 최대 30개를 만듭니다.

확인하려면 Claude에게 **"뉴스봇 수집 돌려줘"**라고 요청합니다. 후보 표와 빠진 기사·이유를 보여 줍니다.

바꾸고 싶으면(언론사 추가·빼기, 제외 단어 추가) Claude에게 말로 요청합니다. 설정은 `accounts/today_news.yaml`의 `collect` 부분입니다.

## 비밀값 넣는 곳

- 실제 값은 `news-bot/.env` 파일에만 붙여 넣습니다.
- 채팅에는 절대 붙여 넣지 않습니다.
- 메모장으로 `.env`를 열어 `이름=` 뒤에 값을 붙여 넣고 저장합니다. 띄어쓰기는 넣지 않습니다.

## 값이 잘 들어갔는지 확인

Claude에게 "뉴스봇 check 돌려줘"라고 요청합니다. 값은 보여 주지 않고 입력 여부만 ✅/❌로 알려 줍니다.
