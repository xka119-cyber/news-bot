# 뉴스봇 운영 설명서

갱신: 2026-11-04 · 현재 단계: M5 완료 (다음: M6 자동 실행)

새 인스타 채널(예: 심리테스트)을 만들 때는 [NEW_CHANNEL.md](NEW_CHANNEL.md) 순서를 따릅니다.

지금은 Claude가 명령을 직접 실행해야 미리보기·게시가 됩니다. M6에서 GitHub가 정해진 시간에 자동으로 실행하게 됩니다.

## 정해진 내용

- 저장소: https://github.com/xka119-cyber/news-bot (공개)
- 공개 범위: 코드, 카드 이미지, 승인 전 초안, 상태 파일은 누구나 볼 수 있습니다. 비밀값은 올라가지 않습니다.
- 브랜드: 오늘의 3분 뉴스
- 색상: 흰 배경, 남색 글자, 노란 강조색 (M3에서 시안을 보고 바꿀 수 있음)

## 연결된 계정 (2026-11-04 확인)

| 서비스 | 내용 |
|---|---|
| 업무용 메일 | dailycard.lab (계정별로 `+news` 같은 별칭 사용) |
| 인스타그램 | today3min.news (프로페셔널 계정) |
| 텔레그램 봇 | @today3min_news_bot (작동 확인, 내 대화방 메시지 도착) |
| 메타 | 앱 `dailycard-newsbot`, 비즈니스 포트폴리오 `dailycard.lab` (비즈니스 인증은 나중에) |
| Claude API | 개인 콘솔 조직, 워크스페이스 `newsbot`, 월 한도 3달러 (2달러에 알림) |

- 인스타 게시 권한(`instagram_content_publish`) 확인, 하루 게시 한도 100회.
- 메타 연결 과정에서 광고 계정 `dailycard.lab`이 자동으로 생겼습니다. 결제 수단이 없어 비용은 나가지 않습니다.

## 설계서와 달라진 점

- 메타가 이제 **비즈니스 포트폴리오**가 있어야 인스타 토큰을 줍니다(설계서에는 없던 단계).
- 인스타 토큰은 **시스템 사용자 토큰**(메타 화면 표기: 만료되지 않음)입니다. 설계서의 60일 연장 기능(M6)은 "토큰이 살아 있는지 점검" 위주로 바꿀 예정입니다.
- 이 토큰은 `graph.facebook.com` 주소에서만 작동합니다(설계서는 `graph.instagram.com`). 게시 코드(M5)는 이 주소와 API v26.0을 씁니다.
- 카드 이미지는 미리보기 때가 아니라 **승인된 뒤 게시 직전에만** 공개 주소(GitHub `media` 브랜치)에 올립니다. 건너뛴 초안은 공개되지 않습니다.
- 인스타 게시 한도는 설계서의 50건이 아니라 하루 100건입니다(메타 문서에 두 숫자가 섞여 있으나 계정 조회값은 100).

## 뉴스를 모으는 곳 (M1, 균형형)

- 연합뉴스(경제·산업), 동아일보(경제·과학), SBS(경제·생활), 매일경제(부동산), 전자신문, ZDNet Korea
- 기사 본문은 가져오지 않고 **제목·짧은 요약·링크·언론사·시각**만 씁니다.
- 최근 12시간 기사 중 같은 기사·비슷한 제목은 하나만 남기고, 최근 3일 안에 쓴 기사는 뺍니다.
- 정치·선거·사건사고·연예 가십 단어가 들어간 기사, 사진·영상·인사·부고 기사는 1차로 뺍니다. M2에서 Claude가 한 번 더 거릅니다.
- 언론사별로 고르게 섞어 후보 최대 30개를 만듭니다.

확인하려면 Claude에게 **"뉴스봇 수집 돌려줘"**라고 요청합니다. 후보 표와 빠진 기사·이유를 보여 줍니다.

바꾸고 싶으면(언론사 추가·빼기, 제외 단어 추가) Claude에게 말로 요청합니다. 설정은 `accounts/today_news.yaml`의 `collect` 부분입니다.

## 게시물 구성: 1게시물 = 뉴스 1개 (2026-11-04 결정)

표지에서 무슨 소식인지 바로 보여야 탐색 탭에서 퍼지기 쉬워서, 뉴스 3개 묶음 대신 한 게시물에 한 소식만 담습니다.
카드 4장: ① 표지(궁금증 제목 + 한 줄 설명) ② 무슨 일인지 ③ 구체적인 내용·숫자 ④ 그래서 나한테는?

**게시 시각마다 2개** (2026-11-04 결정): 시각마다 서로 다른 소식으로 2개를 만들고, 하나씩 따로 승인합니다. 승인한 것만 그 시각에 함께 올라갑니다(하루 최대 8개). 개수는 `posts_per_slot`에서 바꿉니다.
2번째를 쓸 때는 1번째 기사를 후보에서 빼고, Claude에게 같은 주제를 피하라고 알려 줍니다.

## Claude가 문구 쓰기 (M2)

- 후보 30개 중 1개를 골라 표지 제목(22자)·설명(30자)·핵심 카드 2장(소제목 + 2~3줄)·나한테 의미(60자)·캡션 첫 문장을 씁니다.
- 언론사 이름과 링크는 Claude가 아니라 수집한 데이터에서 그대로 붙입니다(잘못 적을 일이 없음).
- 코드가 다시 검사합니다: 글자 수, 원문 20자 이상 베끼기 → 한 번 다시 쓰게 함 / 원문에 없는 숫자, 제외 단어 → ⚠️ 경고로 표시.
- 캡션에는 게시 시간을 넣지 않습니다(수동 승인이라 시간이 달라질 수 있음).
- 확인하려면 Claude에게 **"뉴스봇 작성 돌려줘"**라고 요청합니다. 결과는 `out/draft.json`, `out/caption.txt`에 저장됩니다.

### 비용
- 1회 작성 약 **$0.002~0.004 (약 3~5원)**, 2026-11-04 실제 측정(다시 쓰기 포함). 하루 4회 × 2개 × 30일이면 **월 약 $1**.
- 월 누적은 `state/costs.json`에 기록되고, 봇 예산 **$2**에 닿으면 작성을 멈춥니다(콘솔 한도 $3과 별개의 안전장치).
- 디자인 작업 때는 Claude를 부르지 않는 샘플 모드(`--mock-llm`)를 써서 비용이 0입니다.

## 카드 디자인 (M3)

- 선택한 시안: **B 스티커** (크림 바탕, 손글씨 스티커, 메모지. 소개 게시물과 같은 느낌). 기울기 없이 반듯하게 다듬음.
- 4장: ① 표지(날짜·분야·큰 제목·설명) ② ③ 핵심(소제목 + 메모지) ④ "그래서 나한테는?" — 모든 장에 출처 표기
- 1080×1350 JPEG. 기사 사진·언론사 로고는 쓰지 않습니다. 게시 시간은 넣지 않습니다.
- 글자가 넘치면 자동으로 줄이고, 80%보다 더 줄여야 하면 ⚠️ 경고를 냅니다.
- 다른 시안(A 깔끔, C 남색)은 1뉴스 구성으로 바꾸면서 정리했습니다. 필요하면 다시 만들 수 있습니다(설정: `design.template`).
- 확인하려면 Claude에게 **"뉴스봇 카드 만들어줘"**라고 요청합니다. 마지막 작성 결과로 `out/cards/`에 4장을 만듭니다.
- 폰트: Pretendard, Jua, 나눔펜 (모두 무료·상업 이용 가능, 라이선스는 `assets/fonts/`에 있음)

## 매일 할 일: 텔레그램 승인 (M4)

1. 게시 약 1시간 전에 @today3min_news_bot 대화방으로 **카드 4장 + 미리보기 메시지**가 2세트 옵니다. 제목에 (1/2), (2/2)가 붙습니다.
2. 카드를 넘겨 보고, 메시지의 **⚠️ 확인할 점**(원문에 없는 숫자 등)을 봅니다. 원문 링크로 기사를 열어 볼 수 있습니다.
3. 미리보기마다 **[✅ 승인]** 또는 **[⏭ 건너뛰기]**를 **한 번만** 누릅니다.
   - 봇은 늘 켜져 있는 게 아니라 정해진 때만 실행돼서 응답을 읽습니다. 그래서 누르면 버튼이 잠깐 빙글 돌다 멈출 수 있는데 **정상**입니다. 여러 번 누를 필요 없습니다.
   - **둘 다 올리려면 맨 아래 [✅ 모두 승인 (2개)] 버튼을 한 번** 누르면 됩니다. 아직 결정 안 한 것만 승인됩니다.
   - 하나씩 누를 때는 하나 누르고, 빙글 도는 게 멈춘 뒤(10초 안팎) 다음 것을 누릅니다. 동시에 누르면 뒤의 것이 전달되지 않습니다(2026-11-04 확인).
   - 다음 실행 때 버튼이 사라지고 "✅ 승인됨 — 21:30에 올라가요" / "⏭ 건너뛰었어요" 한 줄이 달립니다.
4. 버튼을 안 누르고 게시 시간이 지나면 **올리지 않습니다**(건너뛰기와 같음).

- 내 대화방에서 누른 버튼만 인정합니다. 다른 사람이 봇을 찾아 들어와도 승인할 수 없습니다.
- 미리보기가 안 오거나 실패하면 같은 대화방에 "어느 단계에서, 왜" 실패했는지 메시지가 옵니다.
- 직접 해 보려면 Claude에게 "뉴스봇 미리보기 보내줘" → 버튼 누르기 → "뉴스봇 승인 확인해줘"라고 요청합니다.

## 인스타 게시 (M5)

- **승인한 초안만** 올라갑니다. 건너뛰었거나 게시 시각까지 안 누른 초안은 올리지 않고 "⌛ 건너뛰었어요"가 옵니다.
- 게시되면 미리보기 메시지에 **"📸 올라갔어요! + 게시물 링크"**가 달립니다. 실패하면 "❌ 게시 실패 + 이유"가 옵니다.
- 같은 초안이 두 번 올라가지 않습니다(중간에 끊겨도 다시 실행하면 이어서 처리).
- 게시한 기사는 기록해 두고 3일 동안 다시 고르지 않습니다.
- 첫 게시: 2026-11-04 22:31 「분양가 25%만 내고 입주?」 (카드 4장, https://www.instagram.com/p/DfUkfu6gbO8/)
- 같은 날 23시 2건(날씨·전월세 신탁)은 메타 차단 때문에 실패했다가, 풀린 뒤 23:1x에 다시 올렸습니다.

### 문제 해결: "API access blocked" (게시가 모두 실패할 때)
- 메타가 앱을 예방 조치로 잠시 막은 상태입니다(2026-11-04 첫 게시 직후 한 번 겪음). 토큰 문제가 아닙니다.
- developers.facebook.com에 로그인해 들어가면 "액세스 권한이 복원되었습니다" 같은 안내가 뜨고 풀립니다. 다른 알림이 있으면 Claude에게 캡처를 보냅니다.
- 풀리면 실패한 초안은 Claude에게 "실패한 거 다시 올려줘"라고 하면 됩니다(시간 지난 뉴스인지 먼저 확인).
- 직접 해 보려면 Claude에게 "뉴스봇 미리보기 보내줘" → 승인 → "뉴스봇 게시해줘"라고 요청합니다.

### 게시 시간
- 정해진 시각: **07:30 · 12:00 · 18:00 · 21:30** (설정: `accounts/today_news.yaml`의 `slots`)
- 각 시각 약 1시간 전에 미리보기가 오고, 그 시각에 게시 단계가 돌면서 승인된 것만 올립니다.
- 승인을 일찍 눌러도 정해진 시각에 올라갑니다. 시각을 넘겨 누르면 그 초안은 건너뜁니다.
- M6부터 GitHub 예약 실행은 몇 분~수십 분 늦어질 수 있습니다. 그래서 소개 글·카드에는 시간을 적지 않습니다.

## 비밀값 넣는 곳

- 실제 값은 `news-bot/.env` 파일에만 붙여 넣습니다.
- 채팅에는 절대 붙여 넣지 않습니다.
- 메모장으로 `.env`를 열어 `이름=` 뒤에 값을 붙여 넣고 저장합니다. 띄어쓰기는 넣지 않습니다.

## 값이 잘 들어갔는지 확인

Claude에게 "뉴스봇 check 돌려줘"라고 요청합니다. 값은 보여 주지 않고 입력 여부만 ✅/❌로 알려 줍니다.
