## 자동 실행 (M6, GitHub Actions)

| 작업 | 한국 시각 | 하는 일 |
|---|---|---|
| generate (미리보기) | 06:25 · 10:55 · 16:55 · 20:25 | 수집 → Claude 작성 → 카드 → 텔레그램 미리보기 2개 + 아래 키보드 버튼 |
| publish (게시) | 07:30 · 12:02 · 18:02 · 21:30 | 버튼 응답 읽기 → 승인된 것만 게시 → 링크 보고 |
| maintenance (점검·정리) | 월 04:10 | 인스타 연결 점검(문제 시 텔레그램 알림), 7일 지난 초안 정리 |

- GitHub 예약 실행은 **몇 분~수십 분 늦을 수 있습니다.** 미리보기가 조금 늦게 와도 정상입니다.
- 실행 기록 보기: 저장소 → **Actions** 탭. 초록 ✓ = 성공, 빨간 ✗ = 실패(텔레그램에도 이유가 옵니다).
- 직접 실행: Actions 탭 → 왼쪽에서 작업 선택 → **Run workflow**. generate는 게시 시각(HH:MM)과 "샘플 문구(비용 0)"를, publish는 특정 초안 ID를 넣을 수 있습니다. 보통은 Claude에게 부탁하면 됩니다.
- **잠깐 멈추기**: Actions 탭 → 작업 선택 → 오른쪽 위 `...` → **Disable workflow**. 다시 켤 때는 Enable. (또는 Claude에게 "뉴스봇 멈춰줘")
- 기록 보관: 승인 상태·사용한 기사·Claude 비용은 저장소의 `media` 브랜치(`state/`, `drafts/`)에 있습니다. 매번 새로 시작하는 GitHub 실행이 이 기록을 이어서 씁니다.
- 승인 전 초안의 글(draft.json)은 공개 저장소에 올라갑니다. 카드 이미지는 승인된 것만 올라갑니다.
- 공개 저장소는 60일 동안 활동이 없으면 예약 실행이 꺼질 수 있습니다. media 브랜치에 매일 기록이 쌓여 보통은 괜찮지만, Actions 탭에 꺼졌다는 안내가 보이면 Enable을 누릅니다.
- GitHub 컴퓨터(미국)에서는 전자신문 RSS가 열리지 않을 때가 있습니다(2026-11-04). 다른 언론사로 후보는 충분합니다.

## 설계서와 달라진 점

- 메타가 이제 **비즈니스 포트폴리오**가 있어야 인스타 토큰을 줍니다(설계서에는 없던 단계).
- 인스타 토큰은 **시스템 사용자 토큰**(메타 화면 표기: 만료되지 않음)입니다. 설계서의 60일 연장 기능(M6)은 "토큰이 살아 있는지 점검" 위주로 바꿀 예정입니다.
- 이 토큰은 `graph.facebook.com` 주소에서만 작동합니다(설계서는 `graph.instagram.com`). 게시 코드(M5)는 이 주소와 API v26.0을 씁니다.
- 그래서 설계서의 주 1회 `token-refresh`(60일 토큰 갱신) 대신 `token-check`(연결 점검, 실패 시 텔레그램 알림)를 둡니다. `GH_PAT`는 필요 없습니다.
- 카드 이미지는 미리보기 때가 아니라 **승인된 뒤 게시 직전에만** 공개 주소(GitHub `media` 브랜치)에 올립니다. 건너뛴 초안은 공개되지 않습니다.
- 인스타 게시 한도는 설계서의 50건이 아니라 하루 100건입니다(메타 문서에 두 숫자가 섞여 있으나 계정 조회값은 100).

## 게시물 구성: 1게시물 = 뉴스 1개 (2026-11-04 결정)

표지에서 무슨 소식인지 바로 보여야 탐색 탭에서 퍼지기 쉬워서, 뉴스 3개 묶음 대신 한 게시물에 한 소식만 담습니다.
카드 4장: ① 표지(궁금증 제목 + 한 줄 설명) ② 무슨 일인지 ③ 구체적인 내용·숫자 ④ 그래서 나한테는?

**게시 시각마다 2개** (2026-11-04 결정): 시각마다 서로 다른 소식으로 2개를 만들고, 하나씩 따로 승인합니다. 승인한 것만 그 시각에 함께 올라갑니다(하루 최대 8개). 개수는 `posts_per_slot`에서 바꿉니다.
2번째를 쓸 때는 1번째 기사를 후보에서 빼고, Claude에게 같은 주제를 피하라고 알려 줍니다.

## 매일 할 일: 텔레그램 승인 (M4)

1. 게시 약 1시간 전에 @today3min_news_bot 대화방으로 **카드 4장 + 미리보기 메시지**가 2세트 옵니다. 제목에 (1/2), (2/2)가 붙습니다.
2. 카드를 넘겨 보고, 메시지의 **⚠️ 확인할 점**(원문에 없는 숫자 등)을 봅니다. 원문 링크로 기사를 열어 볼 수 있습니다.
3. **입력칸 자리에 뜬 버튼**(아래 키보드)으로 고릅니다. 안 보이면 입력칸 옆 네모 4개 아이콘을 누릅니다.
   ```
   [✅ 모두 승인 (07:30)]  [⏭ 모두 건너뛰기 (07:30)]
   [✅ 1번 승인 (07:30)]   [✅ 2번 승인 (07:30)]
   ```
   - 누르면 그 글자가 **내 메시지로** 대화방에 올라갑니다(정상). 번호 버튼은 여러 개 눌러도 됩니다.
   - 봇은 정해진 때만 깨어나서, 누른 즉시 답장은 없습니다. 게시 시각에 "✅ 승인됨", "📸 올라갔어요! + 링크"가 오고 버튼이 내려갑니다.
4. 안 누른 것은 게시 시각에 **올리지 않고** "⌛ 건너뛰었어요"가 옵니다. 지난 시각 것은 쌓이지 않고, 버튼은 늘 지금 기다리는 시각 것 하나만 뜹니다.

- **왜 아래 키보드인가 (2026-11-05)**: 메시지 안에 붙은 버튼은 봇이 2~3분 안에 대답하지 않으면 텔레그램이 누름 기록을 버립니다. 정해진 때만 깨어나는 봇은 그래서 승인을 못 읽었습니다. 아래 키보드 버튼은 글 메시지로 남아 24시간 보관됩니다.
- 게시 시각이 살짝 지나도 GitHub 실행이 아직이면(늦어지는 중) 누른 것이 반영됩니다. 실행이 끝난 뒤 누르면 "이미 처리됐거나 게시 시각이 지난 버튼이에요" 답장이 옵니다.
- 내 대화방에서 내 계정이 보낸 버튼 글만 인정합니다. 다른 사람이 같은 글을 보내도 승인되지 않습니다.
- 미리보기가 안 오거나 실패하면 같은 대화방에 "어느 단계에서, 왜" 실패했는지 메시지가 옵니다.
- 직접 해 보려면 Claude에게 "뉴스봇 미리보기 보내줘" → 버튼 누르기 → "뉴스봇 승인 확인해줘"라고 요청합니다.

## 더 많은 사람에게 보이게 하기 (2026-11-05)

인스타가 밝힌 노출 기준은 **본 시간, 도달 대비 좋아요, 도달 대비 보내기(DM 공유)**이고, 탐색 탭은 **저장·공유**를 많이 봅니다. 검색(인스타·구글)은 캡션 앞부분·대체 텍스트·프로필 이름의 **단어**를 봅니다. 해시태그는 분류용 3~5개면 충분합니다.

봇이 자동으로 하는 것:
- 캡션 첫 줄 = 표지 제목(핵심 단어), 둘째 줄 = 검색할 법한 질문
- "📌 저장해 두면… 친구에게도 보내 주세요" 한 줄 (저장·보내기 유도, 과한 구걸 문구는 금지)
- 해시태그 = Claude가 뽑은 기사 주제어 2~3개(예: #전월세안심신탁) + 고정 태그로 채워 5개
- 카드마다 대체 텍스트(alt text) — 화면 글을 그대로 옮김(숨은 키워드 넣지 않음)

사람이 해야 하는 것 (한 번만):
- 프로필 **이름 칸**에 검색어 넣기. 예: `오늘의 3분 뉴스 | 경제·생활 뉴스 요약` (아이디 말고 이름 칸)
- **소개글**에 "매일 4번, 출퇴근길 3분 경제·생활 뉴스 카드" + 누구를 위한 계정인지 한 줄
- 설정 → 개인정보 → **검색 엔진 색인(Search engine indexing)** 켜져 있는지 확인 (프로페셔널 계정은 기본 켜짐, 구글에도 노출)
- 댓글이 달리면 **그날 안에 답글** (초기 노출에 도움)
- 좋은 게시물은 **스토리로 공유**, 프로필에 **하이라이트** 하나 만들기

나중에 (M7·M8): 릴스(신규 도달이 가장 큼), 인사이트로 저장·보내기·탐색 유입 비율 보기, 잘 된 게시물 유형 찾기.
